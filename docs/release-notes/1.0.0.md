# ModelDeck 1.0.0

ModelDeck is now a complete package: the app bundles, installs, and manages
its own CLIProxyAPI, so one DMG gets you from a fresh Mac to a working
multi-account deck with nothing to install by hand.

## The managed proxy

- **Bundled CLIProxyAPI** — the app ships a signed proxy binary built from
  pinned upstream source, supervises it as a real process, and never touches
  your auth files. The pin (upstream tag + commit) travels inside the app,
  and every pin bump has to pass a live compatibility suite before it ships.
- **First-launch flow** — a fresh install asks consent before managing
  anything; an existing CLIProxyAPI setup gets a visible adoption offer, and
  "stop managing" rolls back cleanly to what you had.
- **Keys provision themselves** — a freshly-seeded config gets its
  management key generated and placed automatically (0600 from birth); no
  manual key file steps.
- **The daemon and app stay in sync** — the daemon learns the app's
  managed-proxy state directly, so the dashboard reflects reality instead of
  inferring it.

## Watching your accounts

- **Silent-401 blackout alerts** — three consecutive routed failures on an
  enabled pool member raise a visible alert in the deck and dashboard; one
  success clears it. No more discovering a dead credential hours later.
- **Fix expired credentials in-app** — an expired pool credential can be
  re-logged-in end to end from ModelDeck itself, through the proxy's own
  management API.

## App surfaces

- **Dashboard window** — the full analytics dashboard in a native window,
  served loopback-only.
- **Deep links** — `modeldeck://` links open the app on the right view.
- **About panel** — third-party credits (CLIProxyAPI, Sparkle) in the
  standard About panel, reachable from the menu-bar icon's context menu.

## Hardening

- Every daemon route now refuses non-loopback peers at the kernel
  peer-address level, ahead of any hostname check.

## Scope — what 1.0 is not

- **macOS only** (macOS 14+, Apple silicon). Windows and Linux are not
  planned for this release line.
- **No iOS companion** — the CloudKit-sync design (issue #18) stays parked.

# ModelDeck 1.0.0 go-live

The release-day sequence for the 1.0 label as #405 defined it, in the
0.4.6-GO-LIVE shape: ordered steps, a verification after each, stop at the
first failure. Commands use placeholders and never print identities,
credentials, or database rows. Run every command from the clean ModelDeck
checkout that builds the signed artifact. zsh note (the release-gate lesson):
`cmd | tail` reports tail's status — capture `status=$?` on the bare command,
never at the end of a pipeline.

## 1. Version 1.0.0 in both sources + release checks

Bump `VERSION` and `package.json` to `1.0.0` in one commit (tripwire
version-sources-agree enforces agreement; release-checks re-verify it).

Verify:

```sh
test "$(cat VERSION)" = "1.0.0"
node -e 'const p=require("./package.json"); process.exit(p.version === "1.0.0" ? 0 : 1)'
npm run release:check
status=$?
test "$status" -eq 0
```

`release:check` also re-runs the slice-B pin-bump compat suite against the
pinned CLIProxyAPI build — the live-evidence receipt (pin + binary SHA +
captured bodies) must be current, not stale. A stale receipt exits 1 by
design; regenerate it with the compat suite against the suite's OWN spawned
instance only (never 8317/3867 — the queue read is destructive).

## 2. Mirror deliverables exist and are committed

Three artifacts that do not exist before #425 (all per
docs/research/issue-404-public-mirror.md):

- `NOTICES` at the repo root — CLIProxyAPI attribution (MIT text + source
  pointer at the pinned commit).
- App `Credits.rtf` — the same attribution, visible in the app's About.
- `docs/RELEASE.md` — the reproducibility recipe (pin → build → embed →
  sign → notarize), the **upstream-watch checklist step** (a release checks
  the pin against upstream releases and records the decision), and the
  **CVE-only expedite path**: a pin bump outside the normal cadence is
  justified only by a security fix, and rides the slice-B compat suite the
  same as any bump — the suite is the bar, urgency does not waive it.

Verify:

```sh
test -s NOTICES && test -s docs/RELEASE.md
find macos -name 'Credits.rtf' | grep -q Credits.rtf
git status --porcelain | wc -l | grep -qx '0'
```

## 3. Build, sign, notarize the 1.0.0 artifact

The 0.4.6 path unchanged: `scripts/release-dmg.sh` from this clean checkout
(never from a `mktemp` path — decision 0030), signing identity from the
keychain (`security find-identity -v -p codesigning`), notary profile
`modeldeck-notary`. The embedded proxy binary is built from the pinned source
by `scripts/build-cliproxyapi.sh` — never glob-delete its
`modeldeck-cliproxyapi-build.*` temp dirs while a build runs.

Verify (notarization + staple on the produced DMG):

```sh

spctl -a -t open --context context:primary-signature -v "dist/ModelDeck-1.0.0.dmg"
```

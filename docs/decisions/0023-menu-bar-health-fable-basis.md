# 0023 — Menu-bar icon health always uses the Fable basis

- Date: 2026-08-05
- Links: #257, #258, PR #259

The deck's health verdict follows the user's Fable/Weekly view toggle, but the
menu-bar icon's color deliberately does not — it always reflects Fable's basis. A
persistent always-visible indicator needs one stable, consistent meaning rather than
following a toggle the user may not remember setting.

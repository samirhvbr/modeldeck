# 0013 — Bundling MIT CLIProxyAPI in the PolyForm-NC public mirror is compatible

- Date: 2026-08-14
- Links: #404

MIT's only obligation is notice-inclusion and is silent on the surrounding product's
license; PolyForm-NC's restrictions govern only ModelDeck's own copyright, not a bundled
third party's. Attribution ships as a repo-root notices file plus in-app Credits.rtf,
both generated from one pin-file source so they can't drift, and the pin/build files
stay out of the mirror's scrubbing so the mirror remains self-reproducible.

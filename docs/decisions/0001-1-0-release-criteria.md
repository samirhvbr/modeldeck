# 0001 — 1.0 release criteria and non-goals

- Date: 2026-08-14
- Links: #405, #378, #395, #396

1.0 means the bundled managed proxy, the app window, the Swift-shell scope, and the
adoption flow — with the silent-401 blackout alert (#395) and in-app credential fix
(#396) promoted to 1.0-mandatory, because a managed proxy that fails silently is worse
than an unmanaged one. Windows/Linux, iOS, and forking CLIProxyAPI are explicitly out
of 1.0.

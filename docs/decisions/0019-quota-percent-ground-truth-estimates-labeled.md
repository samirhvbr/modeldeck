# 0019 — Quota percent is ground truth; estimates are always labeled

- Date: 2026-08-09
- Links: docs/usage-analytics-grilling-2026-08-09.md

Every usage view is denominated primarily in percent of each account's real provider
windows; token counts and counterfactual dollars are secondary. Attributed per-project
window-burn (a fitted model) is always visibly marked as an estimate with its fit
quality shown. Chosen after an archive-based estimate contradicted Tim's lived
experience and traced to an undercount — provider percentages don't have that failure
mode — and raw source files are retained so the warehouse stays a rebuildable derived
copy.

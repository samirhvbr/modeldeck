🔑 Next: Keychain permission prompts

First, right as the service starts, macOS will say “security” wants to use confidential information stored in “modeldeck” — that item is ModelDeck's own service key, a random token this app just created so only ModelDeck can change its local service. It is not your Claude or Codex sign-in, and it never leaves this Mac. Click Always Allow (macOS may ask for your Mac login password once).

Then, as each Claude subscription first refreshes, macOS will ask permission for the service to read that subscription's sign-in from your Keychain — one prompt per subscription, from macOS itself. Choose Always Allow (it may ask for your password once per subscription); plain Allow asks again on every refresh. Properly signed app updates won't re-prompt.
